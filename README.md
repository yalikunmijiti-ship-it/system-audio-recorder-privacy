# System Audio Recorder

**System Audio Recorder** ist eine Audioaufnahme-App für Android und Windows.
Sie ermöglicht die Aufnahme von Systemaudio und unterstützt unter Android
zusätzlich das Smartphone-Mikrofon.

## Funktionen

### Android

- Aufnahme von Systemaudio
- Aufnahme über das Smartphone-Mikrofon
- Kombinierte Aufnahme von Systemaudio und Mikrofon
- Start, Pause, Fortsetzen und Stopp über ein verschiebbares Bedienfenster
- Anzeige von Aufnahmedauer und Lautstärkepegel
- Speicherung als WAV-Datei
- Benutzeroberfläche auf Deutsch, Englisch und vereinfachtem Chinesisch

Die fertigen Aufnahmen werden gespeichert unter:

`Interner Speicher/Music/SystemAudioRecorder`

### Windows

- Aufnahme des wiedergegebenen Systemtons
- Auswahl des Audioausgabegeräts
- Auswahl der WAV-Qualität
- Auswahl eines eigenen Speicherordners
- Anzeige von Aufnahmedauer und Lautstärkepegel

## Bedienung unter Android

1. Gewünschte Aufnahmequelle auswählen.
2. In der Vollansicht **Aufnahme starten** antippen.
3. Die erforderlichen Android-Berechtigungen bestätigen.
4. Im eingeblendeten Bedienfenster **START** antippen.
5. Die Aufnahme mit **Pause**, **Fortsetzen** oder **Stopp** steuern.

Die eigentliche Aufnahme beginnt erst nach dem Antippen von **START** im
Bedienfenster.

## Erforderliche Berechtigungen

Je nach Aufnahmeart benötigt die App Zugriff auf:

- das Mikrofon,
- die Android-Freigabe zur Aufnahme von Systemaudio,
- Benachrichtigungen,
- einen Foreground-Service und
- die Berechtigung zur Anzeige des Bedienfensters über anderen Apps.

Android zeigt die entsprechenden Berechtigungsdialoge vor der Verwendung an.

## Datenschutz

- Audioaufnahmen werden lokal auf dem Gerät verarbeitet.
- Die App lädt keine Aufnahmen auf einen Server hoch.
- Es werden keine Werbe-, Analyse- oder Trackingdienste verwendet.
- Die App benötigt kein Benutzerkonto.
- Gespeicherte Aufnahmen können jederzeit vom Nutzer gelöscht werden.

Vollständige Datenschutzerklärung:

**https://github.com/yalikunmijiti-ship-it/system-audio-recorder-privacy/blob/main/index.html**

## Voraussetzungen und Hinweise

- Für die Aufnahme von Android-Systemaudio wird Android 10 oder neuer benötigt.
- Nicht jede Android-App erlaubt die Aufnahme ihres Wiedergabetons.
- DRM-geschützte Inhalte können stumm bleiben.
- Stereo-Mikrofonaufnahme hängt von der Hardware des Smartphones ab.
- Für kombinierte Aufnahmen werden Kopfhörer empfohlen, damit die abgespielte
  Musik nicht zusätzlich über das Mikrofon aufgenommen wird.
